# Johnny Acierto Tabong — Portfolio

Full-Stack Developer | Laravel | React JS | C# .NET

Personal portfolio site built with React, styled-components, and React Router.

## Sections

- **About** — professional summary
- **Skills** — technical skills and core skills
- **Experience** — professional work history
- **Recent Work** — selected projects and screenshots
- **Contact** — contact info and form
